sheep-table

A column is a name and two templates. The table owns the data and everything done to it — sorting, filtering, paging — and past a thousand rows it stops paginating and scrolls instead.

Everything, at once

Eight columns: a frozen identity column that renders two fields and sorts by the surname, filters that search across fields and one that reads >150000, a status column ordered by sequence rather than spelling, right-aligned figures, fixed widths, and an actions column that does neither. Press a funnel to filter a column. Push it over a thousand rows and the paginator gives way to a scroller.
